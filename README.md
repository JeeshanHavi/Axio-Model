# Axio-Model
An advanced, local-first AI automation platform that pairs a dual-network architecture with Ollama LLMs. It bridges the gap between conversational intelligence and cross-platform automation, allowing users to seamlessly control desktop apps, web environments, and IoT devices.

## Overview
Axio is an advanced AI platform designed to combine autonomous decision-making with versatile automation capabilities. It runs on a dual-based local neural network architecture paired with a large language model (LLM) from the Ollama library, enabling both computational intelligence and natural language understanding. The system can retain contextual information, learn from interactions and perform complex multi-step tasks
